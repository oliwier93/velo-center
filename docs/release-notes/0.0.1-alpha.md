# VeloCenter 0.0.1-alpha

First alpha release of the VeloCenter desktop application.

## Highlights

- Avalonia desktop shell for a local-first cycling analysis workflow
- Core, infrastructure, and SQLite persistence foundations included in the packaged app
- Windows release artifacts: installer executable and portable ZIP package

## Notes

- This is an alpha release intended for early testing
- Existing installs should be closed before running the installer again
